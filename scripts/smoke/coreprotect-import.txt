# then looks the history up and rolls it back from it. Needs a fresh flat overworld and a fresh Hawkeye
# database, within three hours of generating. The second import must add nothing. The rollbacks prove the
# block states (the stairs CoreProtect stored with and without block data) and the item components (the
# sword's name and enchantment, the potion's colour) survived the import.
hawkeye status => connected
forceload add 0 0
forceload add 16 16
setblock 20 -60 20 minecraft:chest
setblock 20 -58 20 minecraft:chest
hawkeye import status => No import is running
hawkeye import coreprotect => Import done: 19 event(s)
hawkeye import coreprotect => Import done: 0 event(s)

hawkeye lookup u:#tnt t:3h r:#world => #tnt broke
hawkeye lookup u:#kill t:3h r:#world => killed zombie
hawkeye lookup u:#hopper t:3h r:#world => diamond_sword
